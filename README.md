# AppleCore-Store

Адаптивная витрина iPhone на основе приложенного макета. Каталог, переключение цвета и объёма памяти, динамический пересчёт цены, характеристики, корзина и оформление заказа с генерацией номера и электронного чека заказа.

## Публикация на GitHub Pages
1. Создайте репозиторий на GitHub.
2. Загрузите в корень `index.html`, этот `README.md` и папку `payment` с QR-кодами.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.

## Цены, фото и настройки
- Цена меняется при выборе памяти и рассчитывается по базовым ценам Apple Store Ireland в евро: EUR × 90,2429 ₽ × 1,20 с округлением до 100 ₽.
- Для каждой модели доступны три изображения с официальных страниц Apple; они загружаются из интернета. Выберите миниатюру, чтобы сменить главное фото. Расцветка в заказе фиксируется отдельно.
- В карточке каждой модели доступно подробное описание и полный список характеристик.
- Характеристики приведены для ознакомления; перед продажей проверьте их и наличие у поставщика.
- Выберите сеть USDT, сверьте её с кошельком и используйте соответствующий QR/адрес. TON требует memo `2162666292`; минимум BEP-20 — 5 USDT, остальные минимумы указаны на странице. Сумма USDT ориентировочная: RUB / 80,5381 (курс USD ЦБ на 24.10.2026), уточните курс перед переводом.
- Доставка рассчитывается отдельно: стоимость и срок зависят от города и адреса.
- GitHub Pages — статический сайт: он не проверяет блокчейн, не сохраняет заказы на сервере и не отправляет файл скриншота продавцу. После выбора файла сайт выдаёт подтверждение со статусом «ожидает ручной проверки»; передайте заказ и файл продавцу вручную. Для автоматической проверки, приёма и передачи платежей потребуется сервер или платёжный сервис. Адрес магазина для заказов: `devideu@zohomail.eu`. Кнопка Email открывает черновик письма с данными заказа; покупатель должен нажать «Отправить» и приложить скриншот вручную.

Сайт использует Tailwind CSS CDN, Font Awesome CDN, Google Fonts и официальные изображения Apple.


После формы покупатель увидит QR/адрес оплаты. После прикрепления скриншота сайт выдаст распечатываемое подтверждение заказа и загруженного файла. Перевод всё равно требует ручной проверки; это не фискальный чек.
